Contributor Onboarding Guide

Welcome to the Zeppelin Student Builders repository!

Getting Started

1. Fork the repository to your GitHub account.
2. Create a new branch for your contribution.
3. Make your changes in the new branch.
4. Review your changes before committing.
5. Commit your changes with a clear commit message.
6. Push your branch to your fork.
7. Create a Pull Request to the original repository.
8. Clearly describe what you changed and why.

Before Creating a Pull Request

- Make sure your changes are relevant to the repository.
- Check that you have not modified unrelated files.
- Use clear and meaningful commit messages.
- Review your changes before opening the Pull Request.
- Provide a clear description of your contribution.

Need Help?

If you are unsure about any part of the contribution process, check the repository documentation or ask the community for guidance.
